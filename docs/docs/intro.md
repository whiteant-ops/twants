# Introduction

TWANTS is a framework-agnostic UI system built with semantic HTML, CSS tokens, and small optional JavaScript modules.

It works with plain HTML, Vite, Laravel, Django, Tauri, Wails, React, Vue, and Svelte.

<Callout type="info" title="Framework-agnostic by design">
The CSS layer does not depend on a runtime. Interactive behaviors are exposed as small JavaScript modules.
</Callout>
