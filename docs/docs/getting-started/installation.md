# Installation

## Install from npm

```bash
npm install twants
```

## Import styles

```ts
import "twants/styles";
```

Granular entry points are also available:

```ts
import "twants/tokens";
import "twants/theme";
import "twants/components";
```

<Callout type="warning" title="Tailwind CSS v4">
TWANTS uses Tailwind CSS v4 CSS-first configuration. Use Tailwind v4 or later in projects that consume the Tailwind integration.
</Callout>
