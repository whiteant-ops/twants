Introduction

TWANTS is a framework-agnostic UI system built with Vite and Tailwind CSS v4, inspired by WinUI / Fluent Design. It ships ~100 customizable components using CSS variables, semantic tokens, and accessible HTML.

Installation

npm install twants

Quick start

import "twants/styles";
import { ThemeSwitcher } from "twants";

ThemeSwitcher.init();
